Our Program Outline

The 4-Week Learning Journey

A structured curriculum designed to build capabilities systematically from foundational steps to building live portfolios.

WEEK 1
Introduction to Algorithmic Logic

Understand computational thinking. Master flowcharts, logical loops, variables, and conditions through gamified blocks.

WEEK 2
Web Scaffolding & Design

Get hands-on with HTML5, CSS3 foundations, responsive flexboxes, grids, and Bootstrap framework components.

WEEK 3
Interactive JS Logic & APIs

Integrate browser inputs. Write core logic handling events, fetching external REST APIs, and rendering active JSON cards.

WEEK 4
AI Integrations & Capstone Project

Understand Prompt Engineering, build GPT-powered tools, integrate Firebase Auth/Store, and host Capstone web portals.
